## How to Navigate

Above, you'll see a bunch of .md files.  "MD" stands for Markdown.  They should be pretty clearly named according to which parts of the story they contain; click on the appropriate one for the part of the story you want, and read it.  This site will render the Markdown into readable text for you.  The Markdown itself is readable on its own (and if it weren't, then Markdown wouldn't be the format I use to write in), but it's much nicer to see it in rendered form, where all the `_italic_ and **bold**` text is _italic_ and **bold** and not just a bunch of underscores and asterisks.  There are options at the top of the file viewer that should let you switch back and forth between raw and rendered output, if you aren't getting the view you want (or just want to see how I did something in the raw Markdown formatting).

***Avoid anything that says "notes" or is in the Notes folder.***  These are world-building notes, and there are ***MASSIVE*** spoilers in those files.  Some of the info in my notes never even makes it into the story; it's just there so I can remember how I've decided some feature in the mechanics of the story work, so I can write about it more consistently.  If you're really curious about a particular feature, it's better to _just ask me how it works._  I'll either pull out the relevant chunk of the notes and send it to you, or ask you how far you've gotten so I can explain without spoiling anything for you.

If you're already familiar with git or other source control tools, it is possible to view _diffs_ between different points in my work on the story.  This is just a view of what's changed between one point in the story's development and another.  If you're here just reading this for the first time, I would advise against trying to do this; some of the prior revisions may reveal spoilers by showing chunks of the story that have been moved or revised, or may shift major chunks of the story from one place to another.  If I want you to see what's changed as a result of a particular edit or series of edits, I'll send you a link to that diff directly.
